# AirCard Netlify License Backend

This directory is a standalone Netlify site. It provides the license API and a small admin page.

## 1. Create the database

Create a Supabase project, open the SQL editor, and run schema.sql.

The database function locks the license row during redemption. The same key cannot be redeemed twice at the same time.

## 2. Configure Netlify

Create a new Netlify site from this directory. In Site configuration -> Environment variables, add:

    SUPABASE_URL=https://YOUR_PROJECT.supabase.co
    SUPABASE_SERVICE_ROLE_KEY=YOUR_SERVER_ONLY_SERVICE_ROLE_KEY
    LICENSE_ADMIN_KEY=YOUR_LONG_RANDOM_ADMIN_KEY

The service role key must only exist in Netlify server environment variables. Never put it in the App or public files.

## 3. Deploy from Windows

    cd netlify-license
    npm install
    npx netlify login
    npx netlify init
    npx netlify env:set SUPABASE_URL https://YOUR_PROJECT.supabase.co
    npx netlify env:set SUPABASE_SERVICE_ROLE_KEY YOUR_SERVER_ONLY_SERVICE_ROLE_KEY
    npx netlify env:set LICENSE_ADMIN_KEY YOUR_LONG_RANDOM_ADMIN_KEY
    npx netlify deploy --prod

After deployment, the admin page is:

    https://YOUR_SITE.netlify.app/

The App endpoints keep the old filename-style paths:

    POST /api/license_redeem.php
    POST /api/license_status.php

## 4. Point the IPA to Netlify

Change LicenseAPIBaseURL in ios-app/Info.plist to:

    https://YOUR_SITE.netlify.app

The Netlify functions are mapped to /api/license_redeem.php and /api/license_status.php, so no Swift endpoint changes are needed. Rebuild and sign the IPA after changing the URL.

## Security notes

- Keys are generated by the admin function and only SHA-256 hashes are stored.
- A key is bound to the first device ID that redeems it.
- Repeating a redemption request on the same device is idempotent.
- The App checks the backend before each wallpaper download.
- For strict enforcement, the wallpaper download gateway must also check the same license table. A modified IPA can remove a client-only check.
